CREATE BUILD AND RUN

1) Setup UnityHub as normal
2) Install the editor for Unity 6.3
3) Install build support for your platform
4) Create a Universal 3D Project
5) Navigate to Project root folder and clone git repository
6) Open project in UnityHub
7) File --> Build Profiles
8) Select the appropriate Build Profile
9) Press "Build and run"
10) Save to Builds/[System OS]/
11) Give the build a name
12) Let the build sequence run
13) Enjoy!
